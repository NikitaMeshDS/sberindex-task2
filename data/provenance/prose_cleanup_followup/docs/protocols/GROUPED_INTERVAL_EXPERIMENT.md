# Отдельная калибровка интервалов по группам МО

Фиксируется перед расчётом новых групповых методов, после изучения общего нормирования. Это продолжение исследования на том же2024, не независимый тест.

Цель: проверить, уменьшает ли раздельная калибровка неоднородность покрытия по уровню расходов, не скрывая ширину и промахи. Четыре группы: квартиль среднего расходаМО за2023 на фиксированной оценочной когорте. Границы и назначения сохраняются, группировка по ошибкам2024 запрещена. Состав групп не меняется между датами.

Сравниваются четыре фиксированных метода: прежние global raw3m/global scaled_forecast3m и те же два метода отдельно внутри квартилей. Квантили в каждой группе считаются по расходным фактам только предыдущих месяцев; окно3м, начальная калибровка июль–август, оценка сентябрь–декабрь2024. Те же три модели, h1,80/95%, лаг0. Повторно используем проверенный calibrate_panel; конфигурацию предыдущего опыта не изменяем. Нет поиска числа групп/параметров/победителя. Малый объём каждой группы раскрывается (64МО,128/192 калибровочных строк), эти строки не считаются независимыми временными повторениями.

Оценки: покрытие, минимальное квартильное и помесячное покрытие, средняя ширина, intervalscore и групповые результаты. Все методы имеют те же ID/цели/факты/точечные прогнозы. Групповые методы не обязаны достигать номинального покрытия или превосходить общий. Никакая теория покрытия по зависимым временным рядам не заявляется.

Тесты: чужая группа не меняет калибровку группы; будущие/текущие факты не меняют выданных границ; отсутствующая группа вызывает отказ. Контроли воспроизводят предыдущее приложение. Старые результаты и рабочий выпуск сохраняются; новые файлы — отдельное приложение.
