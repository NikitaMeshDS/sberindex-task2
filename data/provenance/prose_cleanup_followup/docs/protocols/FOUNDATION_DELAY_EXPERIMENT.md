# Нормированные foundation-модели при задержке — 5 октября 2026

Продолжение уже исследованного эксперимента задержки, без нового выбора модели или изменения NEXT_HOLDOUT_PROTOCOL. Зафиксировано до нового inference и просмотра его ошибок.

## Сценарий и входы

Выпуск в конце месяца t, бизнес-цель t+1. При задержке d последнее наблюдение t−d, эффективный горизонт от наблюдения до цели 1+d. Задержки 0/1/2, четыре общие цели сентября–декабря 2024. Месячная задержка — основной гипотетический сценарий, 0/2 — чувствительность; исторические даты публикации расходов неизвестны.

Когорта — прежние 256 ID, выбранные по полноте 2023. Chronos получает только полную наблюдаемую историю до последнего доступного месяца. Набор подаваемых в inference ID определяется исключительно этой историей; наличие будущего целевого факта не влияет на состав входного batch. После inference оцениваются наблюдаемые цели на пересечении пар всех моделей и задержек. Выбор по всему будущему году запрещён; исключения целей отдельно раскрываются.

Модели: Prophet, сезонная, фиксированная смесь 75/25, HGB без календаря, Chronos-Bolt Tiny и Chronos-2 — каждый raw и с известным сезонным профилем. Профиль только по полным 2075 рядам 2023. Ревизии из config.json, CPU, два потока, batch64, медиана. Raw и normalized запускаются отдельно. Профиль восстанавливает будущий месяц из 2023; факты целевого 2024 для этого не используются.

## Что новое и что повторено

Prophet/сезонная/смесь читаются из прежнего `asof_reporting_delay_predictions.parquet`. Для задержок 0/2 Chronos и HGB берутся из сохранённых `foundation_seasonal_predictions.parquet` и `calendar_predictions.parquet`, без изменения прогноза. При задержке1 отсутствующий эффективный h2 для Chronos вычисляется впервые на тех же ревизиях. HGB с фиксированными параметрами повторно обучается только на2023 и рекурсивно прогнозирует два шага; это воспроизведение существующей модели, не новая настройка. При совпадающих h1/h3 прогнозах отдельная повторная проверка HGB подтверждает тождество сохранённой версии.

## Оценка

Для каждого d одинаковые пары ID/target во всех моделях и во всех задержках. Основная MAE равновзвешена по целевым датам; pooled MAE, R², WAPE, NMAE к уровню2023 и количества дат/МО/пар. Разности кандидата против сезонной/Prophet и normalized против своего raw; доля месяцев и муниципальных средних с улучшением, исключение каждой одной даты. Никаких p-values или независимости МО во времени. Ни модель, ни задержка не выбираются по итоговой MAE.

После нового расчёта сохранить индивидуальные прогнозы/время/протокол с исходными и кэш-хешами. Refresh повторяет только таблицы из защищённого кэша, без загрузки torch/весов. Проверки подтверждают месячную арифметику, неизменность истории при изменении будущего, единые пары/факты, исходные кэши и пересчёт метрик. Все результаты на изученном2024, четыре временных повторения; история предобучения Chronos не позволяет исключить временное пересечение. Презентация не меняется.
