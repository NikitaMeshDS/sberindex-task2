Сравнение: прежняя сбалансированная24месячная панель, только как ретроспективный ориентир. При пропуске нельзя оценить сигнал/тревогу: NaN сохранён, EWMA/CUSUM сбрасываются, rolling использует только непрерывное наблюдаемое окно после пропуска. Это фиксированная политика, не оптимизация по оценочному полугодию.

Сигнал: годовой логарифмический рост, текущая медиана доступных МО выбранной когорты, индивидуальный уровень января–июня. Стандартизация умножает остаток на pooled_MAD/regularized_MAD, сохраняя типичный масштаб для прежнего CUSUM drift0,025. За всё полугодие сохраняются доля новых тревог и нагрузка по наблюдаемым МО-месяцам. Задержка описывает только обнаруженные воздействия; доля необнаруженных сообщается отдельно.
