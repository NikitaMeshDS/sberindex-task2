# Более сильные варианты Prophet

Задано после внешнего отзыва, до просмотра результатов новых вариантов. Весь2024 уже изучен; это исследовательский тест, не независимая оценка.

Цель: проверить, сохраняется ли преимущество сезонного ориентира при добавлении сезонности самому Prophet. Контроль — прежний Prophet без годовой сезонности и сезонная модель из operational_workflow, одинаковые пары256ID/даты/горизонты. Когорта и общий сезонный профиль определяются только по2023. Расширенное окно: origin декабрь2023…ноябрь2024, цели только2024; h1/3/6/12. Наh6 до7целевыхдат, наh12 одна. Прежнее позднее сравнение сохраняется и не смешивается с новым усреднением. Лаг0; история строго доorigin, пропуски не заполняются.

Два фиксированных варианта: Prophet с годовой гармоникой Fourier order3, period365.25, prior_scale.1; Prophet с дополнительным мультипликативным регрессором pooled_profile−1, prior_scale.1, standardize=False. Общий профиль = суммы расходов всех2075 пригодныхМО2023, нормированные на годовое среднее. Значения регрессора будущих месяцев известны из замороженного2023. Weekly/daily отключены как прежде; uncertainty_samples0. Другие стандартные настройки Prophet сохраняются. Выход обрезается снизу нулём. Не ищем prior/order/mode по2024.

Основные сравнения: MAE с равным весом целевыхдат, R² pooled и within-MO, skill=1−MAE/MAE_reference. Два ориентира: сезонный профиль и seasonal naive(тот же месяц прошлого года). ПриростыMoM/YoY рассчитываются только там, где истинное базовое значение доступно наorigin; h>1 дляMoM допускается только chained прогноз с таким же происхождением, иначе показатель не вычисляется. Не используем неизвестный будущий факт как базу прогнозного прироста.

Первый цикл использует всю ранее зафиксированную256-IDкогорту; не выдается за все2075МО. Ограничения и отсутствие расширения на весь набор раскрываются. Общие ковариаты могут иметь временную прогнозную информацию, даже без межмуниципальной вариации; эффект не является причинным.

[Настройки](../../configs/prophet_seasonality.json). Основа настройки: [документация Prophet](https://facebook.github.io/prophet/docs/seasonality%2C_holiday_effects%2C_and_regressors.html). Новые варианты — отдельное приложение, старые числа не переписываются.
