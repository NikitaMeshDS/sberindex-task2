# Сравнение калибровки интервалов

Фиксируется до расчёта новых вариантов; все месяцы 2024 уже изучены в проекте. Это исследовательская абляция, не независимый тест и не подбор новой модели.

Цель: проверить недопокрытие интервалов без произвольного расширения по итоговым фактам. Точечные прогнозы Prophet, сезонной модели и смеси не меняются. Горизонт1, целевые сентябрь–декабрь2024, начальная калибровка июль–август; предположение лага0, как в исходном online_intervals. На новый рабочий лаг1 эти интервалы не переносятся.

Фиксированные варианты: raw_3m (старый контроль), scaled_2023_3m (ошибка / средние расходыМО2023), scaled_forecast_3m (ошибка / |прогноз|), adaptive_scaled_2023_3m. Квантили вычисляются по последним трём календарным месяцам с целями строго раньше оцениваемой цели; ни факты текущей цели, ни будущие месяцы не участвуют в её интервале. Масштаб2023 рассчитывается только из2023. Для прогнозного масштаба используется сохранённый прогноз той же строки. Минимальный масштаб1руб.; нижняя/верхняя границы обрезаются снизу нулём. Уровни80%/95%.

Адаптивный вариант стартует с alpha=1−уровень. После каждого оценочного месяца обновляет alpha←clip(alpha+gamma*(alpha_nominal−доля_промахов_месяца),.005,.5); gamma=.05. Это панельная эвристика с одним обновлением на календарный месяц, а не исходный ACI с индивидуальным бинарным откликом. Теоретические гарантии ACI не заявляются. Параметры не выбираются по результатам.

Основные оценки: покрытие с равным весом целевых месяцев, средняя ширина в рублях и относительно масштаба2023, interval score со штрафом2/(1−номинальный уровень), минимальное помесячное покрытие. Покрытие/ширина по квартилям расходов2023 раскрывают неоднородность; границы фиксируются на оцениваемой когорте по2023. Нет p-values: четыре календарных месяца и256МО не являются1024 независимыми наблюдениями. Сравнение ширины важно вместе с покрытием, а не вместо него.

Проверки: изменение будущих фактов не меняет предыдущие интервалы; изменение факта текущей цели не меняет её границы; raw_3m совпадает со старым выходом; исходные точечные прогнозы/факты неизменны; все методы имеют одни ID/цели. Отдельная таблица хранит даты калибровки, квантили и alpha до/после отклика. Пропуски/невалидные масштабы/дубликаты вызывают отказ, не скрытое заполнение.

[Конфигурация](../../configs/interval_calibration.json). Основа идеи последовательного регулирования: [Gibbs и Candès, 2021](https://arxiv.org/abs/2106.00170); для нашей модификации это мотивация, не доказательство гарантии. Выбор рабочего метода отложен до новых данных.
