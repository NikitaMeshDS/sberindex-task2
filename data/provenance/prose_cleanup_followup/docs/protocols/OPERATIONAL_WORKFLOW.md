# Рабочий выпуск и задержанные остаточные модели

Зафиксировано 5 октября 2026 до нового расчёта. Исторический архив уже изучен; дополнительные разбиения не создают независимый временной тест. NEXT_HOLDOUT_PROTOCOL не меняется.

1. Остаточные HGB own/categories/policy: прежние параметры residual_features.json и обучение только на 2023, без зарплатного винтажа 2026. Проверяем бизнес-горизонты 1/3/6/12 и лаги 0/1/2. Решение t, последний факт t−lag, цель t+h. Обучение с концом декабрь2023 допускается только при origin≥декабрь2023. Все доступные цели 2024; история общих расходов положительная и полная, неизвестные категории остаются NaN. Профиль 2023 общий, когорта прежняя256. CBR консервативно ограничен origin, включая обучение; изменение правил доступности ЦБ требует отдельного опыта. Prophet переобучается только на допустимой истории; смесь .75/.25 переносится без настройки. MAE равновесит месяцы, ранние цели до июля и поздние с июля показаны отдельно. Отсутствующие цели, недостаточная история и обучение, ещё не доступное при решении, учитываются в покрытии. Для h12 с лагами1/2 нет допустимых фактов 2024. Новые HGB не повышаются до основного алгоритма по изученному тесту.

2. Исполняемое рабочее правило: смесь .75 сезонного прогноза с .25 Prophet для каждого h1/3/6/12, лаг1 по умолчанию. Это единый инженерный кандидат, а не доказанный победитель всех горизонтов. Профиль учится на полном2023, Prophet на доступной истории, параметры фиксированы. Неполная/неположительная история ⇒ отказ с причиной, без подстановки будущих значений. Вывод включает ID, решение, последний факт, целевой месяц, бизнес- и эффективный горизонт, модель, прогноз/причину отказа. По умолчанию демонстрационный выпуск на декабрь2024; факт декабря при лаг1 не используется. Новости/макро не входят в основной выпуск без подтверждённой доступности.

Прикладной детектор: инженерные предположения, не согласованные реальные затраты: общие расходы, regularized_noise, лаг1, ±20% ступень, срок3месяца, бюджет2 исходных тревоги/100 доставленных МО-месяцев, минимальная доля новых обнаружений50%. Выбирается допустимый метод с наибольшей минимальной по двум знакам чувствительностью, затем меньшей максимальной нагрузкой, затем названием. Если допустимого метода нет — отказ. Поздняя оценка не меняет выбор. Обе части используют те же уже изученные месяцы2024 и те же МО: это разделение назначений синтетического воздействия, не независимые реальные события или временная валидация. Реальные ранние предупреждения остаются нерешённой исследовательской задачей.

4. Единый refresh включает описательные компромиссы, остаточный опыт, задержанный опыт, выбор и демонстрационный выпуск; старые результаты остаются отдельными. Проверка в отдельной установленной среде и перенесённом каталоге с отсутствующими производными результатами сравнивает все численные материалы и рисунки. Кэш Prophet/Chronos основной ветки явно сохраняется; новые остаточные модели и Prophet задержанного опыта обучаются заново. Это не полный повтор тяжёлых фундаментальных моделей и не новый временной тест.
