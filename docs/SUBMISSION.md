## Доступ и подача

Публичный репозиторий для сдачи создан из чистого снимка с одним исходным коммитом. [GitHub Pages](https://NikitaMeshDS.github.io/sberindex-task2/) показывает сохранённые результаты, отчёт и PDF. Основная исследовательская история остаётся приватной. Сборка пакета не отправляет заявку.
