# Прогноз на своих данных

[README](../README.md) · [JSON-конфигурация](../configs/predict.json)

Сайт показывает сохранённые результаты 2024 года. Команда ниже **рассчитывает новые точечные прогнозы** выбранной сезонной модели на CSV или Parquet. Полный исследовательский архив и GPU не нужны.

## Первый запуск

Из корня репозитория, Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-inference.txt
python predict.py --config configs/predict.json
```

Пример использует входящую в репозиторий таблицу, декабрь 2024 и профиль 2023. Ожидается **8092 прогноза для 2023 МО**, цели — январь, март, июнь и декабрь 2025. Это повтор исторического сценария, а не новый доказанный результат качества. Файлы создаются в `run_outputs/forecast_2025_example/`.

Повтор не перезаписывает результат: задайте другую `output_directory` в конфиге. Пути внутри JSON считаются относительно папки JSON, поэтому его можно перенести вместе со своими таблицами.

## Формат своих таблиц

Расходы: одна строка на МО, месяц и категорию, колонки:

| Колонка | Содержание |
|---|---|
| `territory_id` | Целочисленный ID, одинаковый в расходах и справочнике |
| `date` | Месяц: `2025-01` либо дата внутри месяца |
| `category` | Название категории, совпадающее с `category` в конфиге |
| `value` | Средние месячные безналичные расходы жителя в рублях, сопоставимые между месяцами |
| `available_from` | Необязательно: дата публикации/доступности строки, например `2025-02-03` |

Справочник CSV или Parquet: `territory_id`, `region_code`; необязательный `year` — год версии. При наличии `year` выберите `geography_year`. Без него используется переданная единственная версия справочника. Даты публикации географии команда не устанавливает сама.

Нужен **полный календарный год из 12 положительных месячных значений** для сезонных профилей и положительный последний факт за `origin`. МО с неполной историей или отсутствующим последним фактом не прогнозируются; их количество записывается в манифест. Для малых групп и отсутствующего региона применяется общий профиль.

## Что менять в конфиге

| Параметр | Назначение |
|---|---|
| `input_path`, `lookup_path` | Свои расходы и справочник |
| `output_directory` | Новая папка результатов |
| `origin` | Последний месяц известного факта |
| `as_of_date` | Дата доступной информации, не раньше конца `origin` |
| `profile_year` | Полный календарный год профиля, завершившийся к `origin` |
| `geography_year` | Версия справочника, не позже года `origin` |
| `category` | Категория расходов |
| `horizons` | Уникальные положительные целые горизонты в месяцах |
| `region_weight` | Вес регионального профиля, от 0 до 1; выбранное значение 0,5 |
| `minimum_region_municipalities` | Минимум полных МО для отдельного регионального профиля; выбранное значение 10 |
| `growth_rate` | Предполагаемый годовой рост в долях: 0,10 означает 10% |
| `growth_source`, `growth_available_from` | Объяснение ставки и дата доступности её источника |

**17,2% в примере — историческое допущение из источника 2023 года.** Для другого периода задайте обоснованную ставку, известную на дату расчёта. Команда не подбирает её по будущим расходам. Изменение года профиля или параметров — новый вариант применения; прежние метрики 2024 автоматически на него не переносятся.

Факты после `origin` исключаются до обучения. При наличии `available_from` также исключаются строки, опубликованные после `as_of_date`. Без этой колонки предполагается, что вся история до `origin` была доступна; это допущение явно сохраняется.

## Результат и границы

- `predictions.csv`: ID, дата расчётного месяца, целевой месяц, горизонт, последний уровень, точечный прогноз, регион и признак применения регионального профиля.
- `config.json`: копия параметров запуска.
- `manifest.json`: время запуска, SHA256 таблиц, конфигурации и кода, число исключённых строк и МО, допущения доступности.

Команда не строит интервалы без новой калибровки, не запускает автоматически новостной сбор и детектор, не подменяет сохранённые данные сайта. Для оценки качества нужны последующие факты. Проверка режима:

```bash
PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_predict_command.py' -v
```
