# Запрос данных для независимой проверки

Текст подготовлен для команды; организаторам не отправлен.

Здравствуйте! Мы готовим решение задачи №2 конкурса СберИндекс: прогнозирование потребления муниципальных образований и обнаружение структурных изменений.

Для проверки на ранее не использованном временном периоде нужна официальная выгрузка того же показателя средних месячных безналичных расходов жителей МО, что представлен в конкурсном consumption.parquet за 2023–2024 годы:

- Январь–декабрь 2025 года, по возможности также доступные месяцы 2026.
- territory_id, месяц, категория, значение в тех же единицах; в первую очередь категория «Все категории».
- Описание методики и подтверждение сопоставимости с конкурсной выгрузкой: изменения покрытия банковских карт, определения среднего, территориальных границ и фильтра качества.
- Версионный справочник ID/территорий и правила преобразования ID при изменениях муниципалитетов.
- Даты первоначальной публикации каждого месяца и даты исправлений; по возможности исходные месячные винтажи 2023–2025.
- Источник/ссылка, дата версии и условия использования/цитирования.

Горизонт 12 месяцев при задержке 1: решение в январе 2024, последняя доступная история декабрь 2023, цель январь 2025. При задержке 2: первое допустимое решение февраль 2024, цель февраль 2025. Желателен полный 2025, чтобы проверить несколько дат, а не одну. При наличии лишь пересмотренного позднего снимка оценку назовём ретроспективной с гипотетической задержкой, без утверждения о подтверждённой исторической доступности.

Будем признательны за прямую ссылку на публичный набор или возможность получить конкурсное дополнение.
