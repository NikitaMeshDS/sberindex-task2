# Словарь исследования

| Термин в коде или научной литературе | Понятное объяснение |
|---|---|
| МО | Муниципальное образование; территорию соединяем с данными по официальному ID. |
| MAE | Средняя абсолютная ошибка: на сколько рублей прогноз в среднем отличается от факта. Меньше — лучше. |
| R² | Сравнение квадратичной ошибки с простым средним фактов. Может быть отрицательным. Разные варианты R² отвечают на разные вопросы. |
| Within-MO R² | Качество описания изменений внутри муниципалитета после вычитания его среднего уровня. При одной дате не определён. |
| YoY | Изменение относительно того же месяца предыдущего года. |
| Горизонт h | На сколько месяцев вперёд строится прогноз. |
| Origin | Последний месяц, известный при построении прогноза. |
| Когорта | Набор муниципалитетов, участвующих в конкретном сравнении. Для разных опытов он может различаться. |
| Винтаж | Версия данных, доступная в определённую прошлую дату. Современная выгрузка не доказывает прошлую доступность. |
| Available_from | Дата, начиная с которой источник разрешено использовать в расчёте. Для новостей здесь принят сценарий «публикация + один день». |
| Лаг публикации | Задержка между месяцем наблюдения и доступностью его факта. Нулевой лаг в опыте — допущение. |
| Остаток прогноза | Ошибка после сравнения факта и прогноза; детектор использует логарифм их отношения. |
| EWMA | Сглаживание ошибки с большим весом свежих наблюдений. Превышение порога даёт тревогу. |
| CUSUM | Накопление последовательных отклонений; может находить устойчивые изменения, но требует проверки нагрузки тревог. |
| BOCPD | Вероятностный алгоритм поиска смены режима при последовательном получении данных. |
| PELT | Поиск границ изменений по уже известному целому ряду. Его результат нельзя считать ранней онлайн-тревогой. |
| FAR / Null FAR | Частота ложных тревог на специально созданных рядах без изменения. На реальных данных без полной разметки считаем нагрузку тревог. |
| Эпизод тревоги | Непрерывная последовательность превышений; началом считается первое превышение. |
| Блочный бутстрап | Повторный выбор МО или регионов целиком, вместе со всеми их датами, для оценки неопределённости сравнения. |
| 95% доверительный интервал | Диапазон неопределённости при выбранной схеме повторной выборки. Интервал по территориям не заменяет проверку на новых годах. |
| Тест Диболда–Мариано | Сравнение ошибок моделей по датам с учётом зависимости во времени. При слишком малом числе дат вывод ненадёжен. |
| Поправка Холма | Коррекция выводов, когда одновременно проверяется несколько статистических гипотез. |
| Foundation-модель | Готовая модель временных рядов, предварительно обученная на большом количестве других рядов. |
| Zero-shot | Применение готовой модели без дообучения на наших данных. |
| Адаптивный g | Медиана последних трёх месячных медиан годового роста расходов по МО региона; при недостатке истории используется документированный макропоказатель. |
| Bridge / growth bridge | Поправка масштаба при переходе календарного года; в выбранной модели — фиксированный рост 17,2%. |
| Абляция | Сравнение с добавлением и без добавления одного компонента при остальных фиксированных условиях. |
| Утечка будущего | Использование информации, которая ещё не была доступна на дату прогноза. |
| Независимый тест | Данные, которые не использовались для выбора модели, правил, порогов или исследовательских гипотез. |
