# Начать проверку проекта здесь

1. [README: результаты и материалы](../README.md#результаты-и-материалы) — найдите свой критерий и главный результат.
2. [Презентация PDF](../artifacts/presentation.pdf), **21 слайд**. Слайд 2 — итоги и карта, 7 — объяснение метрик, 11 — преимущества foundation-моделей, 19 — ограничения, 20 — выводы; 21 — приложение. [Редактируемый PPTX](../artifacts/presentation.pptx).
3. [Отчёт](research/SUBMISSION_REPORT.md): десять разделов, метод, сравнения, объяснения и источники. [Словарь](research/GLOSSARY.md).
4. [Интерфейс](../dashboard/index.html): откройте локальный файл из архива, выберите Уфу, Яльчикский район или Орск. [Снимок экрана](assets/dashboard-preview.png).
5. В корне компактного комплекта выполните `python3.12 run_review.py --mode verify`. Требуется только Python, без установки библиотек и весов. Ожидается JSON `status: passed`; проверка относится к SHA256, не к новому обучению.

## Важные различия при чтении

- Все четыре основных MAE: **932 / 1272 / 1371 / 1321 руб.** Выигрыш к одному Prophet с профилем: **41,5 / 23,3 / 28,5 / 55,8%**. К лучшему проверенному Prophet h12 выигрыш 54,5% — другой контроль.
- Интервалы по МО/регионам условны на исследованных датах 2024; h12 имеет одну дату. Независимый временной тест ещё не выполнен.
- EWMA F1 0,647 и ложные тревоги 0,046 / 100 МО-месяцев — оценочная синтетика. В реальной панели считаем нагрузку; истина шоков не размечена.
- Новостные публикации, тексты извлечения и подтверждённые фрагменты — разные совокупности. 103 текста / 12 фрагментов / 3 ID; лишь 2 ID в расходной панели. Эпизоды 145 → 145: эффект улучшения не получен.
- Интервалы на графиках примеров иллюстративны. Новые 2025-файлы — исторические симуляции, не прогнозы, выданные в 2024.

Компактный комплект содержит код, итоговые материалы и быструю проверку. GPU для быстрой проверки не нужен. Веса современных моделей не поставляются; точные ревизии фиксированы в конфигурациях. Dockerfile предоставлен, локальная сборка не подтверждена.
