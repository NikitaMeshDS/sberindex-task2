# Сборка слайдов

Презентация содержит 21 слайд. Таблицы и диаграммы в PPTX редактируются; PDF подходит для сдачи. Числа берутся из `artifacts/presentation_data.json`, который собирается из защищённых CSV результатов.

```bash
PYTHONPATH=src python tools/prepare_presentation_data.py
node tools/build_final_presentation.mjs
```

Второй шаг запускается в среде Codex с заданными путями `PRESENTATION_SKILL_DIR`, `ARTIFACT_TOOL_ROOT`, `RUNTIME_PYTHON` и доступным Node.js. Пакет `@oai/artifact-tool` входит в эту среду и не распространяется в репозитории. На обычной машине слайды можно редактировать непосредственно в PPTX; выполнение исследования не зависит от инструмента оформления.

Сборщик проверяет 21 страницу, наличие редактируемых таблиц на слайдах 2/5/6/7/8/9/10/13/14/18/21 и диаграмм на 5/12/13/15, встраивает числовые книги диаграмм и создаёт проверенный `artifacts/presentation.pptx`. Временные файлы остаются в игнорируемых `.presentation-build/` и `artifacts/final/`.

PDF экспортируется из PPTX установленным в предоставленной среде LibreOffice; визуально проверяются все страницы. Исходный скрипт использует шрифт Noto Sans. Прежний PDF сохранён в архивной ветке и не входит в текущий комплект.

Для единого запуска PDF/PPTX используйте `PYTHONPATH=src python -m sberindex.reporting.build_presentation` с теми же переменными, а также `RUNTIME_BIN_DIR` (каталог предоставленного LibreOffice) и при необходимости `RUNTIME_NODE` (полный путь к Node.js). Этот же сборщик вызывается флагом `run_pipeline.py --presentation`; прежний генератор черновика заменён.

Общая таблица на слайде 5 использует одинаковые сохранённые пары десяти моделей, отдельно от полной когорты основного результата. Графики на слайде 12 содержат новые иллюстративные интервалы 80% для выбранной модели: масштаб расходов 2023 года и ошибки предыдущих трёх завершённых месяцев, при сценарии лага 0. Их не переносили от прежней смеси; гарантии покрытия нет. Расчёты: `tools/presentation_comparison_cases.py`, проверки утверждений: `tools/presentation_claim_checks.py`.
