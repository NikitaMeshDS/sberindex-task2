# Сравнение детекторов с годом обучения

Протокол записан до первого расчёта нового опыта. Предыдущие результаты 36/24 месяцев сохраняются. Новые seed закреплены в configs/short_history_review.json: отдельные калибровка, отбор и три оценочных набора. Это независимые симуляции, а не независимый временной тест расходов.

История 12 месяцев, оценка 12 месяцев. Сезонная синусоида плюс независимый нормальный шум 0,03 в логарифмах, без тренда. Null / постоянный сдвиг / импульс, амплитуды ±0,06/0,12/0,18. Начало на индексах 2–6, длительность 2–4; возврат всегда наблюдается. Месячный профиль оценивается только по году обучения. Одно наблюдение на сезонный месяц означает повышенный шум прогноза.

Сравниваются пять прежних онлайн методов, настоящие PELT и KernelCPD, а также объединение CUSUM + spike. Пороги онлайн — 99-й процентиль максимума по 12 месяцам на 400 null рядах. Совместный канал калибруется по максимуму двух нормированных score; квантили каждого канала не считаются контролем общей ошибки. Штрафы офлайн: минимальный из фиксированной сетки, удовлетворяющий null бюджету на калибровке.

Две разметки: все границы (начало и возврат импульса) и раннее обнаружение начала. Для второй полнота считается по onset; сопоставленный возврат нейтрален для precision, остальные несопоставленные тревоги — FP. Однозначное сопоставление ±1 месяц. F1 onset учитывает FP до/после начала, а не только долю найденных положительных рядов. Все границы и возвраты отдельно остаются в таблице.

Единый выбор онлайн метода: среди прошедших null FAR ≤0,2 тревоги / 100 null МО-месяцев на отборе максимизировать onset F1, при равенстве — имя. Жёсткий минимум recall не используется в этом новом раннем профиле; низкий recall должен быть показан. Если ни один не проходит бюджет — выбор отсутствует. Метод фиксируется до чтения оценочных наборов, все результаты публикуются. Совместный канал не назначается победителем заранее.

Задержка онлайн условна на найденных событиях, пропуски отдельно. Для офлайн получение ответа — конец всего окна плюс сценарный месяц публикации. Числа синтетики не гарантируют реальную частоту ложных тревог и причинную связь с новостями.
