# Восстановление тел официальных новостных страниц

## Область опыта

Новая партия состоит из 80 URL, ранее исключённых из расширенного корпуса с причиной `historical_search_index_not_saved_article_body`. Предыдущие 12 и 17 входов, ответы и результаты остаются неизменными. Это расширение уже изученного корпуса, а не независимая контрольная выборка.

Официальные страницы повторно открыты 7 октября 2026 через инструмент веб-чтения. Сохранён каждый ответ и метаданные запроса. Требуется совпадение видимой даты страницы с датой записи. Навигация до даты и типовые нижние блоки отбрасываются. Поисковые сниппеты не принимаются за статью. Полнота выдержки, историческая неизменность и реальная дата доступности не подтверждены. Снимок 2026 нельзя объявлять сохранённой версией 2024.

## Извлечение и связка

Используются прежние checkpoint Qwen2.5-1.5B, его точная ревизия, prompt, детерминированная генерация и лимиты 5500 символов входа / 350 новых токенов. Ответ должен содержать дословную цитату и поддержанный ею тип события. Неподтверждённые даты и масштаб остаются неизвестными. ID, выданный моделью, не принимается: название проверяется внутри цитаты и по официальному справочнику региона/года. Общая региональная публикация не распространяется автоматически на все МО. Лексическая проверка подтверждает упоминание явления, но не различает благоприятный прогноз, предупреждение и наступившее бедствие. Такие фрагменты не являются положительными метками реализованного шока.

Доступность — публикация + один день, как в прежнем сценарии. Для подтверждённых муниципальных связей сохраняется прежнее снижение порога собственного EWMA в 0,75 раза на два месяца. Порог не меняется для получения нужного числа тревог. В реальной панели считается нагрузка эпизодов; без расходной разметки это не частота ложных тревог и не точность обнаружения шоков.

## Воспроизводимость

Пересчитать проверку сохранённых ответов без загрузки весов:

```sh
PYTHONPATH=src python -m sberindex.external.news_body_recovery
```

Продолжить извлечение локальным checkpoint (нужны зависимости и сохранённые веса указанной ревизии):

```sh
PYTHONPATH=src python -m sberindex.external.news_body_recovery --infer
```

Ответы сохраняются после каждой страницы. Частичный или дублированный checkpoint не принимается за завершённую партию. Окончательный `audit.json` содержит SHA входов, кода и снимков; сырой вход и ответы сохраняются в `data/external/news_body_recovery_20261007`.
