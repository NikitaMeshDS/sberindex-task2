Protocol and config fixed before new inference or evaluation. The archive2024 has already been studied; this is a retrospective extension prompted by review, never an independent test.

Use the existing 256 IDs selected by known2023 data, origin December2023 through November2024, horizons1/3/6/12 when target is within2024. No future-completeness selection. An ID/origin is available only if all six categories have positive finite history through that origin. Score each category only when its target is observed. Every model and both seasonal controls receive identical evaluation pairs. This stricter history rule is declared before calculation and its exclusion counts are reported. Profiles are computed separately for six categories on all complete positive2023 histories, not on2024.

Five fixed variants: Chronos-2 univariate; univariate with one category's known-future pooled2023 seasonal profile; explicit within-MO group of six categories; within-MO group with six known-future category profiles; and Chronos-Bolt-base univariate. The raw expense target stays in raw units. Existing seasonal-normalized results are not repeated. Seasonal naive and last-known-level times pooled profile ratio are controls.

This experiment evaluates explicit multivariate group attention, not arbitrary batch-wide sharing.
