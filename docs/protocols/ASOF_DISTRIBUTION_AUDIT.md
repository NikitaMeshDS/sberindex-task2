# Распределение ошибок новых моделей — протокол 5 октября 2026

Исследовательский аудит, без обучения и изменения основного выбора. Написан до расчёта новых групповых результатов. Проверяем, распространяется ли выигрыш десезонирования Chronos на разные МО и группы расходов; отдельно проверяем, насколько позднее преимущество HGB на один месяц зависит от небольшого числа МО. Архив 2024 уже изучен: выводы не независимые.

## Входы и общие пары

Используются фиксированные `foundation_seasonal_predictions.parquet` и `calendar_predictions.parquet`. Берутся поздние origins начиная с июня 2024 для 1/3/6 месяцев и отдельный прогноз 12 месяцев. Из календарной таблицы добавляются только HGB с календарём и без. Идентичный 12-месячный HGB не дублируется под другим именем. Для каждого горизонта строго проверяются одинаковые ключи `(territory_id, origin, target, horizon)` и фактические цели; отсутствующие пары не замещаются и не выбрасываются молча.

Средний уровень расходов и границы четырёх групп берутся только из полного 2023 года по всем 2075 пригодным ID, независимо от пропусков 2024. Регион и название МО берутся из версии справочника 2023 исключительно для описания групп; это не исторический прогнозный признак. ID и отсутствие сопоставленной географии раскрываются проверкой, не заменяются по результатам модели.

## Метрики

- Основная MAE: сначала среднее по МО целевого месяца, затем равный вес целевых дат. Публикуются также pooled MAE, равновзвешенное по датам смещение, WAPE, медиана/90-й процентиль абсолютной ошибки и муниципальной средней ошибки.
- Нормированная ошибка: абсолютная ошибка / средние расходы данного МО за 2023. Публикуется в процентах с равным весом дат, называется NMAE_2023, не MAPE и не ошибка в сопоставимых ценах.
- Концентрация: доля суммы средних муниципальных ошибок у худших `ceil(5% N)` МО. Это описательная сортировка после результата, не правило отбора или прогноз.
- Попарные разности MAE кандидата минус ориентира: отрицательное значение — улучшение. Доля улучшившихся наблюдений и муниципальных средних; равные значения считаются отдельно с допуском 1e-9 руб. Не считать МО независимыми повторениями времени.
- Ориентиры для всех кандидатов: сезонная модель и Prophet. Дополнительно нормированный Chronos против своего raw, HGB с календарём против HGB без календаря.
- Устойчивость: исключение каждой одной даты и каждого одного региона, а также самых дорогих `ceil(5% N)` МО по среднему 2023 среди оцениваемых ID. Фиксированные правила без подбора доли. Исключение даты при одной дате не вычисляется. Эти диапазоны не доверительные интервалы.

Групповые и муниципальные выводы описательные, без p-values, bootstrap-значимости и выбора победителя. Регионы с малым числом МО не дают обобщаемых географических выводов. На 6/12 месяцах одна дата; дополнительная информация о МО не увеличивает число временных повторений.

## Результат и проверка

Сохраняются overview, groups, paired, sensitivity, municipal CSV, аудит входных SHA256/границ и один научный PNG/SVG. Проверка пересчитывает все таблицы; отдельные аналитические тесты проверяют равный вес дат при неравных числах МО, отсутствие утечки в границы, отказ при несовпадении пар и корректный учёт равенства. Основной прогноз, независимый протокол и презентация не меняются.
