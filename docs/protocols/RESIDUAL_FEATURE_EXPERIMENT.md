# Модель поправки и расширение признаков — 5 октября 2026

Зафиксировано до новых расчётов. База 67cf61a. Уже изученный 2024 остаётся ретроспективным. Основной выбор и NEXT_HOLDOUT_PROTOCOL не изменяются.

Обучение только на 2023; профиль сезонности оценивается на той же обучающей панели. Его использование внутри обучающих строк — часть fit, не честный backtest2023. Цель модели: log(факт/сезонный прогноз). Пул прямых переходов с минимумом 3 месяцев истории и всеми наблюдаемыми целями внутри 2023. Горизонты обучения 1…9; прогноз h12 является экстраполяцией вне диапазона и раскрывается отдельно. Модели Ridge(alpha100) и HGB(150 итераций,15 листьев,min_leaf60,L2=10,lr=.05), без поиска гиперпараметров по 2024. Коррекция log ограничена±.5 заранее. Логарифмы требуют положительных значений; отсутствующие категории остаются NaN с флагами, не получают будущую подстановку.

Парные абляции: прошлые общие расходы; плюс прошлые пять категорий (отношение к общему уровню и изменение за последний месяц); плюс доступные решения ключевой ставки ЦБ (только available_from<=origin month-end). Будущая ставка не используется. Новые показатели Росстата допускаются в отдельную абляцию только после проверки единиц/географии/дат; без винтажей обозначаются snapshot+гипотетический лаг, не исторически доступные факты.

Оценка на точных ключах из asof_cohort_scored, фиксированные 256ID по 2023, общие факты и цели. Сезонный, Prophet и смесь сохраняются точно. MAE_date_balanced обязательно, R2,WAPE, месячные разности и leave-one-date; ранниеh1 и поздниеh1 различаются. Остальные горизонты имеют мало дат; нет объявления устойчивого победителяh6/h12. Нового независимого периода не создано. Отдельный сценарий месячной задержки при необходимости использует корректный origin, не подменяет bridge будущим фактом.

Источники/код/config/protocol/result SHA256 сохраняются в отдельном экспериментальном приложении. Не дописывать новый кэш к старому refresh до проверки. Проверки: обучающие массивы неизменны при мутации 2024; признаки наorigin не меняются при мутации будущего; все сравнения по тем же ключам; новости послеorigin не влияют; нулевая поправка воспроизводит сезонный прогноз. Аудит внешних источников и предварительных предупреждений отдельно раскрывает отсутствие новых муниципальных месяцев/событий, если найденные данные несопоставимы.
