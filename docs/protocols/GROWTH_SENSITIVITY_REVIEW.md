# Фиксированная чувствительность годовой поправки

Расширение выполнено после просмотра результатов 2024 года. Сетка закреплена до данного расчёта: g = 0, 5, 7,4, 10, 15, 17,2, 20, 25%. Она не является предварительной регистрацией до исторического holdout. Не выбирать g с минимальной ошибкой; не изменять модель, правила отбора или региональный вес 0,5.

Использовать сохранённые прогнозы hierarchy05 из growth_bridge_review, одинаковые 60 700 пар МО/origin/target/horizon. Преобразование predicted(g) = predicted(0) * (1 + g)^k, k = floor((month(origin)-1+h)/12). Функция построения не получает actual. Actual используется только для MAE после построения прогноза. Профили и базовые прогнозы не переобучать.

Основная MAE: среднее муниципальных абсолютных ошибок внутри target, затем равное среднее по target. Дополнительно публиковать MAE только k>0, число пар и число origin; k=0 должен остаться без изменений. Все пересечения года исходят из декабря 2023: один origin на каждый h; муниципалитеты не являются независимыми временными повторениями.

Рост номинальной зарплаты октября 2023 на 17,2% опубликован 27 декабря 2023. Ноябрьский ИПЦ 7,48% опубликован 8 декабря 2023, добавить отдельным сценарием доступной информации. Декабрьский ИПЦ 7,42%, округлённый до 7,4% в запрошенной сетке, опубликован 12 января 2024: это диагностика ex-post, не доступный декабрьскому origin прогноз. ИПЦ декабрь/декабрь отличается от среднегодового ИПЦ 5,87%.

Зарплата и ИПЦ имеют разные экономические смыслы. Перенос любого из них в номинальные расходы с эластичностью 1 является предположением, а не тождеством или причинной оценкой. Остальные ставки — условные диагностические сценарии. Проверенные Prophet варианты копировать из существующей summary без переобучения и без нового выбора модели.
