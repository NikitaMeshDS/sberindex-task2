# Проверка интерактивного интерфейса

Сайт — автономный просмотр сохранённых данных. Новый прогноз рассчитывается [отдельной командой](PREDICT_NEW_DATA.md).

## Что проверено

128 браузерных проверок в установленном Google Chrome на macOS: открытие `file://`, три реальных примера, все шесть категорий и четыре горизонта, крайние доступные месяцы, поиск по названию/ID и пустой результат, клики по карте и таблице, обе очереди сигналов во всех месяцах и переход из очереди в МО. Показанная ошибка и число новых эпизодов сверяются с сохранёнными данными. Проверены размеры 390, 768, 1280 и 1440 пикселей, ошибки JavaScript не обнаружены.

[Код сценариев](../tools/test_dashboard.cjs). Скрипт требует Node.js и Playwright; путь установленного браузера можно задать через `BROWSER_EXECUTABLE`, путь модуля — через `PLAYWRIGHT_MODULE`. По умолчанию используется Chromium Playwright. Пример при установленном модуле:

```bash
BROWSER_EXECUTABLE="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node tools/test_dashboard.cjs
```

Можно передать URL первым аргументом. JSON результатов и снимки рабочего стола/телефона записываются в `/tmp` либо папку `UI_TEST_OUTPUT`. Скрипт завершится с ненулевым кодом при неуспешной проверке. Запуск не меняет научные данные.

## Границы проверки

Это проверка интерфейса и соответствия сохранённым данным, а не качества прогнозирования. Мобильный размер эмулирован в Chrome, реальные Safari и Firefox в этой проверке не использовались. Прямой браузерный доступ к GitHub Pages из среды автоматизации завершился `ERR_SOCKET_NOT_CONNECTED`; доступность опубликованных страниц и их соответствие локальным файлам проверяются отдельно HTTP-запросами после развёртывания. Внешние новостные сайты могут менять доступность независимо от проекта.
